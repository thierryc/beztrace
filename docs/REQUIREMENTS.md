# Product requirements

## Supported use case

V1 converts a single clean generated glyph or simple monochrome symbol into
closed cubic Bezier contours suitable for continued type-design editing.
Typical input is a 1024x1024 PNG generated by Codex or ChatGPT with one dark or
alpha-defined silhouette on a plain background.

## Functional requirements

### Input

- Accept PNG and JPEG from a local path or standard input.
- Normalize image orientation and convert supported color spaces to a stable
  grayscale coverage field.
- Prefer meaningful alpha as the foreground mask. For opaque input, support
  dark-on-light by default and explicit inversion.
- Support automatic thresholding and a caller-supplied fixed threshold.
- Reject empty, unreadable, truncated, unsupported, excessively large, or
  clearly unsuitable multicolor/texture input with actionable errors.
- V1 input limits are 16 MB encoded size and 4096x4096 decoded dimensions.

### Tracing

- Extract anti-aliased boundaries at subpixel precision.
- Preserve contour/counter topology and discard bounded noise and border-frame
  artifacts.
- Detect intentional corners, straight segments, extrema, inflections, and
  smooth transitions from structural evidence.
- Fit economical lines and cubic Beziers with constrained tangent directions.
- Refine the outline against source coverage without changing intentional
  structure.
- Produce correct outer/counter winding and deterministic contour starts.
- Run the complete typographic cleanup and geometry validation pipeline.

### Coordinates and placement

- Internal and public geometry uses finite Swift `Double` values.
- Neutral output maps the full source canvas into the tuned 1088-unit vertical
  coordinate space, converts to y-up coordinates, and makes no baseline,
  sidebearing, glyph-name, script, or Unicode inference.
- Optional placement explicitly names the source box, target vertical band,
  horizontal metrics mode, and snapping grid.
- Placement must preserve aspect ratio and return a report containing source
  bounds, scale, translation, final bounds, and resolved metrics.

### Output

- JSON schema v1 is the canonical machine contract.
- JSON represents every cubic with two explicit off-curve controls followed by
  its curve on-curve node and exposes smooth/corner intent.
- SVG must render the exact final JSON geometry and winding.
- Output includes resolved options, source hash/dimensions, engine and schema
  versions, outline statistics, bounds, timings, warnings, and placement data.
- Serialization, contour ordering, node ordering, numeric rounding, warnings,
  and hashes must be deterministic.

### Command-line interface

- Provide single-image tracing, batch tracing, inspection, and version/build
  information.
- Allow input and output through files or standard streams.
- Keep stdout free of progress text whenever it carries JSON or SVG.
- Return documented stable exit codes and bounded diagnostic messages.
- Perform no network access and write only explicitly requested outputs.

## Non-functional requirements

- Support macOS 13 or later on native `arm64` and `x86_64`.
- Build with Swift 6 and Apple system frameworks, with no external runtime
  libraries in the distributed executable.
- Use one shared core path for library, JSON, SVG, single, and batch behavior.
- Be safe for untrusted local image contents: bounds-check decoders and arrays,
  cap work and output, and fail closed on invalid numeric state.
- Meet all correctness, quality, performance, memory, signing, and packaging
  gates in `QUALITY_GATES.md`.

## Explicitly out of scope for v1

- Photographs and scans of printed type.
- Arbitrary multicolor, textured, shaded, or overlapping artwork.
- Stroke-centerline recovery or semantic brush reconstruction.
- Multi-master compatibility and interpolation planning.
- UFO, GLIF, Glyphs, OpenType, or designspace writing.
- Learned decision models.
- Apple Vision as the production tracing engine.
- Network URLs, cloud processing, telemetry, updates, or hosted services.
- Glyphs MCP adapters or direct font-document mutation.
